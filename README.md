# Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Features

- 🎨 Modern dark theme design
- 📱 Fully responsive and mobile-friendly
- ✨ Smooth animations and transitions
- 🚀 Fast performance
- 🎯 Easy to customize

## Sections

- **Hero** - Eye-catching introduction
- **About** - Brief bio and skills
- **Projects** - Showcase your work
- **Contact** - Links to social profiles

## Getting Started

1. Clone or fork this repository
2. Customize the content in `index.html`
3. Update colors in `style.css` by modifying CSS variables
4. Replace social media links in the Contact section
5. Push your changes to see them live at `https://trqmhd.github.io`

## Customization

### Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --background: #0f172a;
    --surface: #1e293b;
    --text-primary: #f1f5f9;
    --text-secondary: #cbd5e1;
    --border: #334155;
}
```

### Projects
Add your projects by duplicating the `.project-card` div and updating the content.

### Social Links
Update the contact links with your actual social media profiles.
